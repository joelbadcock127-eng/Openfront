# Proprietary assets removed

The upstream OpenFront repository ships proprietary assets (logos, favicon,
font, music) in this directory under an all-rights-reserved license that only
permits use for contributions to OpenFront itself.

This solo derivative does not use or redistribute those assets. Original
placeholder branding lives in `/resources` (see `images/FrontlineFavicon.svg`
and `icons/icon512_*.png`) and is configured centrally in
`src/core/configuration/Branding.ts`. The upstream LICENSE file is retained
below for reference.
